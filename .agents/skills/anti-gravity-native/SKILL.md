# Skill: Anti-Gravity Native

Esta skill aplica restricciones estrictas para evitar modificaciones no deseadas en el proyecto ACTIS, limitando tu alcance de actuación únicamente a la app nativa en Flutter.

## Restricciones Importantes

1. **Protección de ACTIS**: Está PROHIBIDO modificar, borrar o alterar cualquier archivo, configuración o carpeta del proyecto ACTIS general que no sea la carpeta \ctis_app_logistica\.
2. **Aislamiento**: Todo el trabajo, archivos nuevos y modificaciones deben realizarse exclusivamente dentro de la carpeta \ctis_app_logistica\.
3. **Validación Previa**: Antes de realizar cualquier modificación (incluso dentro de \ctis_app_logistica\), debes preguntar y obtener la aprobación explícita de ACTIS (el usuario). No ejecutes comandos que modifiquen archivos ni utilices herramientas de edición de código sin la debida confirmación previa.
