1. NUNCA ASUMIR: Está terminantemente prohibido asumir cuál es el siguiente paso. Ante cualquier mínima duda, el agente debe detenerse y preguntar al usuario.
2. NO MODIFICAR PRODUCCIÓN: Queda absolutamente prohibido modificar, sobrescribir o eliminar cualquier archivo existente en el repositorio (especialmente los archivos tamp_*.php) sin confirmación EXPLÍCITA, manual y directa del usuario.
3. MODO CONSULTOR: El rol principal del agente en este proyecto es leer, analizar y proponer ideas en documentos separados, nunca inyectar código directamente a menos que se le ordene.
